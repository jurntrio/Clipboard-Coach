# Transactionele e-mailtemplates

Deze templates zijn de bronbestanden voor de Supabase Auth-mails van Sport Visual Systems.

- `confirm-signup.html`: **Authentication → Email Templates → Confirm signup**
- `reset-password.html`: **Authentication → Email Templates → Reset password**

Gebruik als afzender `Sport Visual Systems <noreply@sportvisualsystems.com>` en behoud de variabele `{{ .ConfirmationURL }}` ongewijzigd.
