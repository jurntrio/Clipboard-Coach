# Build Plan

## Build 1 — Basic video tagging

Goal:
Create the smallest working version of Clipboard Coach Studio.

Features:
- Open a local video file
- Play and pause the video
- Add a timestamped tag
- Show tags in a list
- Save tags locally
- Reload saved tags

Not included:
- Players
- Heatmaps
- Clip export
- Reports
- External app/browser import
- Cloud sync
- AI tracking

## Build 2 — Tag categories

Goal:
Make tagging more useful during match review.

Features:
- Add tag categories
- Example categories: positie, kans, goal, start blok
- Filter tags by category
- Edit or delete a tag

## Build 3 — Players and periods

Goal:
Connect tags to players and match periods.

Features:
- Add players
- Assign a tag to a player
- Add periods or blocks
- Filter tags by player
- Filter tags by period

## Build 4 — Export

Goal:
Allow useful review outside the app.

Features:
- Export tag list as CSV
- Export simple match report
- Export selected timestamps
