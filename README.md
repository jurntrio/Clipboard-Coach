# Clipboard Coach Studio

Clipboard Coach Studio is a local desktop app for football match video tagging and analysis.

## Core goal

The app should help a coach import a match video, tag important moments, assign tags to players, and later generate clips, simple reports, distance run, heatmap.

## First build

The first build should be very small:

1. Open a local video file
2. Play and pause the video
3. Add timestamped tags
4. Save tags locally
5. Reload saved tags

## Important direction

The app should be local-first. It should run on my Windows desktop computer and should not depend on cloud accounts in the first builds.
